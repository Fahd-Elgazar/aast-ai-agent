# Book Chapter Structure Discovery
**AAST AI Agent — Graduation Project Thesis Layout Blueprint**

This report proposes the academic structure for the graduation project book, outlining the purpose and academic expectations of each chapter.

---

## 1. Thesis Chapter Layout

### Chapter 1: Introduction & Problem Statement
*   **Purpose:** Establishes the academic context of the project.
*   **Why it exists:** Defines the challenges of university advising (policy scale, credit evaluations, prerequisites, human advisor constraints).
*   **Expected Content:** Project goals, problem definition, system scope, and list of contributions.

### Chapter 2: Literature Review & Related Work
*   **Purpose:** Places the project within current academic research.
*   **Why it exists:** Evaluates existing RAG methods, GraphRAG techniques, intent routers, decision systems, and fault-tolerant architectures.
*   **Expected Content:** Surveys of academic systems, comparison matrices, and analysis of gaps in current research.

### Chapter 3: System Analysis & Design
*   **Purpose:** Outlines the software engineering architecture.
*   **Why it exists:** Translates institutional requirements into a modular, multi-tier system.
*   **Expected Content:** Domain model mapping, database schema designs (Neo4j, SQLite), query routing logic, context fusion models, and failover strategies.

### Chapter 4: Implementation Details
*   **Purpose:** Documents the code-level deployment details.
*   **Why it exists:** Explains how the architecture is realized in code.
*   **Expected Content:** Code breakdowns (Express orchestrator services, Python retrievers, FastAPI routers), API contracts, prompt templates, and middleware configurations.

### Chapter 5: Evaluation & Benchmarks
*   **Purpose:** Validates system performance and accuracy.
*   **Why it exists:** Evaluates the system's accuracy, latency, and resilience.
*   **Expected Content:** Latency timing charts, router accuracy logs, hallucination checks, circuit breaker tests, and system health loops.

### Chapter 6: Conclusion & Future Work
*   **Purpose:** Wraps up the thesis and outlines next steps.
*   **Why it exists:** Summarizes the academic contributions and details a roadmap for future development.
*   **Expected Content:** Project summary, engineering reflections, and future roadmap (e.g., streaming integration, local hosting).
