AI Application & Data Analysis Course — Learn from Experts!

Instructors:
Dr. Mohamed Atef El-Khoreby
Dr. Dina A. Ragab

Duration: 30 Hours | 10 Days | Twice Weekly
Certificate: Accredited Digital Certificate from AAST

Program Highlights:
Instructor-Led Classroom Training
Practical Labs, Homework & Final Exam

Who Should Join?
Anyone passionate about AI, data science, and machine learning — beginners welcome!
(Optional: Basic programming & math knowledge recommended.)

Curriculum Snapshot:
Python Basics & Programming (Variables, Loops, Functions, Lambda, NumPy, Pandas)
Data Analysis & Visualization (Plotly, Data Cleaning, Handling Outliers & Missing Data)
Machine Learning (Regression, Classification, KMeans, Decision Trees, Random Forest, SVM, Neural Networks)
Deep Learning Introduction

✅ Certification Requirements:
Pass final project & exam
Minimum 90% attendance
